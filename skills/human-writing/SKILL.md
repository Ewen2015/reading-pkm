# 人话写作

**目标一句话：写出来的东西要像"某一个人"在说话，不像"一个模型"在输出。**

两件事必须同时成立：

1. **没有 AI 味**——不出现模型那套默认腔调（连接词、行话、排比三连、每段一句金句、
   匀称到没有起伏的句子）。清单与改法见 [`references/ai-tells.md`](references/ai-tells.md)。
2. **符合给定的人设**——语气、用词、结构都贴人设，而不是泛泛的"写得自然"。
   怎么把人设读进来，见 [`references/persona-intake.md`](references/persona-intake.md)。

**人设是输入，不是本 skill 的一部分。** 本 skill 不绑定任何账号：调用方
（第一个是 `rednote-post`）把它**自己的人设文件**传进来，本 skill 读它、照它写。
没人设文件时，先问一句"这是谁在写"，或从调用方上下文里抽——**不要凭空编一个人设**。

下面命令里的 `<skill>` 指本文件所在目录
（通常是 `${CODEX_HOME:-$HOME/.codex}/skills/human-writing`）。
按字面写 `scripts/human_check.py` 会找不到——当前工作目录通常是用户的项目，不是 skill 目录。

## 怎么被调用

一次调用进、一次调用出：

- **进**：要写什么 + **人设**（文件路径，或一段描述）+（可选）该人设的几篇成品。
- **出**：改好的文字 + **改了哪里、对齐人设的哪一条**（不要只说"已润色"）。

`rednote-post` 是第一个调用方：它在「定角度」之后、「写标题与正文」这一步调本 skill，
传入的正是 [`skills/rednote-post/references/persona.md`](../rednote-post/references/persona.md)。
别的写作 skill 照同样的方式接。

## 三步

### 1. 抽声音指纹（先读，别急着写）

读人设文件，把它落成一张能照着写的指纹表；人设没写全的，从成品里抽：

| 维度 | 要落成什么 |
| --- | --- |
| 开口 | 第一句是具体的东西（场景／数字／反直觉断言），还是概括 |
| 人称 | 用"你"还是"我"；平视、俯视还是仰视 |
| 节奏 | 长句多还是短句多；有没有"一句单独成行" |
| 重音 | emoji 领起／单行／符号前缀／加粗（平台不支持就换掉） |
| 用词 | 高频词、口头禅、**禁忌词** |
| 结构 | 段落推进还是编号条目 |
| 收尾 | 回到读者身上，还是总结内容 |
| 必须留的 | 具体到能查的数字／页码／出处；一条"退一步看这本书" |

完整口径、人设文件该有哪些字段、以及怎么从成品里抽，见
[`references/persona-intake.md`](references/persona-intake.md)。**指纹表填不满就别动笔**——
空着的维度，模型会用默认腔自动补上，那正是 AI 味的来源。

### 2. 写 / 改

按指纹写，同时避 [`references/ai-tells.md`](references/ai-tells.md) 里的 AI 味。

**先写完，再删 AI 味**——边写边纠会把句子写拧。删的顺序：

1. 删套话与行话（连接词、赋能、抓手……）；
2. 把抽象名词换成**具体的物／数字／动作**；
3. 打断匀称——长短句交替，该一句成段就一句成段；
4. 读一遍查收尾：是回到读者身上，还是在总结内容。

### 3. 机械自检 + 出声念

```bash
python3 <skill>/scripts/human_check.py <稿子> [--persona <人设文件>] [--strict]
```

它查的只是**能机判的那一半**：

- **硬**（一出现就失败）：AI 味词表、套装句式、人设禁忌词。
- **软**（结构信号，默认只提醒）：排比三连、段落长度过于均匀、
  **`→` 领起的行动行过多**、**同一个 emoji 领起多段**、**破折号过密**。
  后三条的阈值是照着 20 篇已发成品量出来的，见
  [`references/ai-tells.md`](references/ai-tells.md) 第 4.1 节。

**写作时加 `--strict`**：软信号也判失败。已发成品在 `--strict` 下全部 0 命中，
所以不会有误伤——那个"模型把条目写成模板"的毛病，只能这样兜住。退出码 0 才算过。

**另一半脚本查不出——"像不像一个人在说话"——只能出声念一遍**（问题清单见
[`references/ai-tells.md`](references/ai-tells.md) 第 7 节）。念起来像稿子，就回去改；
念起来像在跟人讲话，才算完。**这一步不许省。**

## 硬规矩（一出现就不像人）

1. **不出现 AI 味连接词**：首先／其次／综上所述／值得一提的是／不难发现／让我们一起／
   不得不说／由此可见／众所周知……（完整词表在 `scripts/human_check.py`）。
2. **不用行话**：赋能／底层逻辑／抓手／闭环／颗粒度／对齐／打法……
3. **不做排比三连**（"既要……又要……还要……"），**不每段一句金句**。
4. **不抽象名词堆叠**：每个论断后面跟一个具体的物／数字／动作。
5. **不做总结式收尾**（"总而言之，人生的意义就是……"）。
6. **不夸**：不留"不可多得的好书""强烈推荐"这类没有信息量的推荐语。
7. **不交半成品**：不确定就核实、把断言收缩到能负责的范围、或整条删掉，
   **不写"待核实／需查证"**——这条和 `rednote-post` 是同一条硬线。

## 反 AI 味的三招

1. **具体代替概括**：把"很多人都有这种感觉"换成"写了三行，删了两行，然后去洗了个碗"。
2. **人称 + 动作，代替长定语**：把"在进行深入思考的过程中"换成"你想清楚的时候"。
3. **打破匀称**：长短句交替，该一句成段就一句成段——模型最爱写长度几乎一致的句子。
