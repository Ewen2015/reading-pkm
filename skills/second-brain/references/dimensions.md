# 思考维度表

这张表是**路由层**，不是书单。它回答的是"看这个问题可以加哪一维"，不是"哪本书谈过这个话题"。

- 卡片用 `dimensions:` 字段把自己挂到维度上；`brain.py recall "<问题>"` 先用这张表把问题
  路由到维度，再取该维度下的书。
- **维度数是人为固定的（现在 25 个）。** 书涨到几百上千本，这张表和 `index.md` 都不变大——
  这是它能扩展的原因。书越多，每维挂的书越多，但进上下文的永远只有维度表 + 选中的那几行。
- 加维度要克制：只有现有维度确实装不下某本书的视野时才加。加一个维度，`index.md` 多三行。
- 问法是**用户会说的话**，不是章节标题。换一种说法搜不到，就往这条后面补一句（`·` 分隔，
  **从用户原话里摘**，别自己造书面语）。补完跑 `brain.py eval` 看有没有变好、有没有把别的题弄坏；
  为某道题补的会在题上标 `tuned`，只有「未调参」那一行才算泛化。

格式固定，`brain.py` 按它解析：
`## 维度名` / `说明：一句话` / `问法：说法一 · 说法二 · 说法三`
